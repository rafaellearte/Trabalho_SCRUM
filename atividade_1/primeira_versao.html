Sobre o protótipo

Biblioteca IF

Uma interface simples para que o estudante entenda a disponibilidade de uma sala.

01 / TRANSPARÊNCIA

Informação visível

O aplicativo mostra os horários e deixa claro o estado da sala.

02 / INSPEÇÃO

Teste com estudante

O usuário consulta os horários para verificar se compreende as respostas.

03 / ADAPTAÇÃO

Melhoria da resposta

A mensagem “Sala ocupada” evita que a tela fique sem resposta para 10h.
