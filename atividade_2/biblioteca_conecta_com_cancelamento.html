Como reservar

1. Escolha o horário

Selecione o horário em que deseja utilizar a Sala 1.

2. Consulte a disponibilidade

Verifique se a sala está livre para o período escolhido.

3. Confirme sua reserva

Se o horário estiver disponível, confirme para concluir a solicitação.

4. Cancele se precisar

Na lista “Minhas reservas”, use o botão de cancelamento para liberar o horário.
